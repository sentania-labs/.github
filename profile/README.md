## Hi there

I'm Scott Bowe — Solutions Architect at Broadcom focused on the VCF Automation and Operations stack. I write about this stuff over at [cloudsandunicorns.com](https://cloudsandunicorns.com) when I have something useful to share.

This org is where I keep the projects that benefit from shared self-hosted GitHub Actions runners. Most of what's here is VCF-centric: Terraform modules for VCF Automation (module patterns for blueprints, VM apps, cloud accounts, deployments, and more), Packer-based Windows Server image builds, and VCF Operations management pack content from the vCommunity.

Not everything is polished. A lot of it is working examples that I built for my lab or for customers, things I didn't want to lose, or patterns I keep coming back to. If something's broken or you have a question, open an issue — happy to chat.

There are a few non-VCF projects in here too. ScarGuard is a wildlife detection system I built around an NVIDIA Jetson Orin Nano — it started because a heron ate my fish. That's a whole story.
