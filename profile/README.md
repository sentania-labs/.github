## Hi there

I'm Scott Bowe — Solutions Architect at Broadcom focused on the VCF Automation and Operations stack. I write about this stuff over at [cloudsandunicorns.com](https://cloudsandunicorns.com) when I have something useful to share.

I migrated most of my git work from a personal account, to an organization, primarily to take advantage of GitHub shared runners.  Then I started building stuff, and I can't stop.  You will find a variety of content here.  Much of it is related VMware Cloud Foundation.  Tools that I have created because they scratched an itch, or they provided a useful way to demonstrate a use case to a customer; terraform modules to make my lab environment easier to manage, or to showcase how VCF Automation can truly be a cloud endpoint.

Not everything is polished. A lot of it is working examples that I built for my lab or for customers, things I didn't want to lose, or patterns I keep coming back to. If something's broken or you have a question, open an issue, I will probably drop what I'm doing and fix it.

There are a few non-VCF projects in here too. ScarGuard is a wildlife detection system I built around an NVIDIA Jetson Orin Nano — it started because a heron ate my fish. That's a whole story.
